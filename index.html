BÀI TẬP 01 - PHẦN LÝ THUYẾT

Câu 1: position relative và absolute

Relative: định vị phần tử tương đối với vị trí ban đầu và vẫn giữ chỗ trong bố cục.

Absolute: định vị phần tử theo tổ tiên gần nhất có position khác static và không giữ chỗ trong luồng bố cục thông thường. 

.container {
    position: relative;
}

.box {
    position: absolute;
    top: 20px;
    right: 20px;
}

Để responsive, nên kết hợp Flexbox, Grid, đơn vị linh hoạt và media query; đồng thời kiểm tra đường dẫn tài nguyên khi triển khai website.

Câu 2: Domain, DNS và Hosting

Domain là tên miền dùng để truy cập website. DNS phân giải tên miền thành thông tin máy chủ. Hosting lưu trữ các tệp website để người dùng truy cập.

Quy trình triển khai:

  1. Hoàn thiện HTML, CSS và JavaScript.
  2. Đưa mã nguồn lên hosting.
  3. Cấu hình DNS nếu sử dụng tên miền riêng.
  4. Kiểm tra đường dẫn, giao diện và HTTPS.

Câu 3: var, let và const

  • var: phạm vi hàm, có thể khai báo lại.
  • let: phạm vi khối, có thể gán lại.
  • const: phạm vi khối, không thể gán lại.
var ten = "An";
let tuoi = 20;
const lop = "CNTT";

tuoi = 21;

console.log(ten, tuoi, lop);

Dùng Console và breakpoint trong Developer Tools để kiểm tra lỗi JavaScript.

Câu 4: Event Delegation

Event Delegation là cách gắn trình xử lý sự kiện vào phần tử cha để xử lý sự kiện từ các phần tử con. 

document.getElementById("danhSach")
    .addEventListener("click", function(event) {
        if (event.target.tagName === "LI") {
            alert(event.target.textContent);
        }
    });

Ưu điểm là giảm số lượng trình xử lý sự kiện và hỗ trợ các phần tử con được thêm động.
